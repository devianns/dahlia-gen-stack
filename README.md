# DAHLIA💫 Character Image Project

닉네임 **DAHLIA💫**를 상징하는 캐릭터의 외형과 분위기를 유지하며, 일상과 판타지의 여러 장면을 이미지 에셋으로 확장하는 프로젝트입니다.

## 시작하기

- [작업자 지침](AGENTS.md)
- [캐릭터 바이블](docs/character-bible.md)
- [시각 탐구·누적 학습 노트](docs/visual-study.md)
- [공통 프롬프트](prompts/character-base.md)
- [실험 계획 템플릿](prompts/experiment-template.md)
- [에셋 생성 기록](generation-log/README.md)

## 디렉터리

- `images/`: 검토를 마친 이미지 에셋. 장면, 표정, 판타지, 의상, 포즈 분류와 저장 규칙은 [이미지 라이브러리 안내](images/README.md) 참조
- `docs/`: 캐릭터 및 세계관의 기준 문서
- `prompts/`: 재사용할 프롬프트 템플릿
- `generation-log/`: 프롬프트와 결과 평가 기록

새 장면을 만들 때는 공통 프롬프트에 장면만 추가하고, 결과를 확인한 뒤 에셋과 생성 기록을 함께 커밋합니다. 이미지 생성은 작업 환경의 이미지 생성 도구를 사용합니다. 생성 도구나 모델의 세부 정보가 확인되지 않으면 로그에 미상으로 기록합니다.

여러 생성 묶음에서 얻은 관찰과 다음 탐구 방향은 [시각 탐구 노트](docs/visual-study.md)에 누적합니다. 이 기록은 다음 작업자가 참고할 프로젝트 문서이며 모델을 자동으로 재학습시키지는 않습니다.
