# 달리아 시각 탐구·누적 학습 노트

이 문서는 생성 이미지에서 관찰한 점을 다음 작업의 프롬프트와 검토 기준으로 이어 주는 프로젝트 기억이다. 새 장면을 만들 때 이전 기록을 확인하고, 생성 묶음이 끝나면 발견한 점과 다음 실험을 갱신한다.

여기서 말하는 `학습`은 사람이 결과를 관찰해 문서와 프롬프트를 개선한다는 뜻이다. 이미지 생성 모델이 이 저장소를 자동으로 읽거나, 기록만으로 모델 가중치가 바뀌는 것은 아니다.

## 유지할 기준과 바꿔 볼 요소

| 계속 알아볼 수 있게 유지 | 장면마다 바꾸며 탐구 |
|---|---|
| 긴 흰 머리와 빙청색·라벤더 음영 | 그림체, 선화와 채색, 재료감, 명암 |
| 청록빛 파란 눈 | 전신·반신·얼굴 시트, 화면비와 카메라 각도 |
| 분홍 별 장식과 청록 리본 | 포즈, 표정, 동작, 시선 |
| 흰 깃털 날개 | 일상·계절·축제·무대·판타지 상황 |
| 캐릭터의 단독/중심성 | 평상복·계절복·공연복·판타지복 |

핵심 외형은 고정하되, 매 이미지에 별빛이나 장식적인 배경을 강제로 넣지 않는다. 다양한 표현에서 정체성이 얼마나 잘 남는지를 살피는 것이 탐구 목표다.

## 현재까지의 탐구 지도

이 표는 기존 에셋과 생성 기록을 요약한다. 표본이 작으므로 보편적 결론이 아니라 지금까지 본 결과다.

| 축 | 이미 다룬 예 | 다음에 넓힐 방향 |
|---|---|---|
| 일상 상황 | 차, 숲 산책, 카페, 베이킹, 비 온 뒤 공원 | 공부, 취미, 실내 휴식, 교통수단, 다른 계절 |
| 특별한 상황 | 천문대 탐험, 바닷가, 불꽃놀이, 단독 무대 | 눈 축제, 비 오는 야시장, 낮 공연, 여행 중 돌발 장면 |
| 표정 | 미소·놀람·수줍음·졸림·결심을 한 시트에서 탐색 | 감정 강도 차이, 시선과 눈썹 변화, 같은 표정의 여러 화풍 |
| 구도와 동작 | 전신 정면, 걷기, 앉기, 소품 들기, 단독 공연 | 측면·후면, 낮은 시점, 높은 시점, 달리기·점프·휴식 |
| 착장 | 가디건, 원피스, 유카타, 수영용 래시가드, 앞치마, 공연복 | 바지 중심 코디, 우천·한파 착장, 무대 의상 변주 |
| 표현 방식 | 수채화풍, 구아슈·색연필 질감, 셀 셰이딩, 플랫 컬러, 파스텔 라인아트, 디지털 구아슈풍 | 두꺼운 선화, 제한 팔레트, 잉크 워시, 부드러운 그래픽 포스터풍 등 |

이미지별 상세 경로와 전체 프롬프트는 [`generation-log/README.md`](../generation-log/README.md)에서 주제별 기록으로 따라간다. 이미지에 글자·로고가 필요한 별도 요청이 없는 경우에는 시각 실험에 포함하지 않는다.

## 지금까지의 관찰

아래는 현재 에셋에서 확인한 관찰이다. 원인에 대한 설명은 가설로 남기고, 반복 실험 전에는 캐릭터 기준으로 확정하지 않는다.

1. **핵심 외형 단서를 짧고 명확하게 반복하면 장면과 착장이 달라져도 알아보기 쉽다.** 흰 머리, 청록빛 눈, 분홍 별핀, 청록 리본, 흰 날개가 여러 장면에서 반복됐다.
2. **전신 프레이밍은 지시와 실제 포즈에 함께 좌우된다.** `head to shoes visible`, `both shoes visible`, 화면 가장자리 여백을 조합하면 전신이 분명해진다. 앉거나 소품을 사용하는 장면은 포즈에 따라 인물이 크게 잡힐 수 있으므로 결과를 확인해야 한다.
3. **한 프롬프트를 변주하는 것보다 행동과 착장을 각각 명시한 프롬프트가 장면 분류에 유리하다.** 해변 세트에서는 산책, 얕은 물, 연 날리기, 독서처럼 행동을 나눠 독립 에셋으로 남겼다.
4. **표현 방식을 바꾸면 같은 팔레트도 분위기가 달라진다.** 수채화·구아슈 질감은 부드러운 장면에, 플랫 컬러와 셀 셰이딩은 읽기 쉬운 동작과 무대 장면에 쓰기 좋았다. 작은 표본의 현재 인상이며 다음 묶음에서 다시 평가한다.
5. **프롬프트에 없는 글자나 로고가 생길 수 있으므로 결과 검토가 필요하다.** 사용자가 금지한 참조 이미지의 요소는 프롬프트에 넣지 않고, 첨부 이미지를 생성 입력으로 전달하지 않는다.
6. **계절·이동·작업·판타지 장면에서도 핵심 외형 단서가 읽힌다.** 새 8장에서는 봄 정원, 가을·겨울 산책, 독서, 기차 여행, 공예, 온실 탐험, 비 오는 날 휴식을 각각 다른 행동과 배경으로 표현했다. 관찰로는 흰 머리와 청록빛 눈, 별핀, 리본, 날개가 모두 식별되지만 일부 앉은 구도에서는 날개나 하체가 프레임 밖으로 이어진다.
7. **재료감과 구도 변화는 장면에 맞게 적용할 수 있다.** 이번 세트는 수채화·색연필, 구아슈, 잉크 선, 파스텔을 사용했고 전신·앉은 중경·가로형 휴식 구도를 섞었다. 현재 표본에서는 부드러운 재료감이 정원·휴식에, 선명한 선과 작업 소품이 공예 장면에 잘 어울려 보인다. 이는 추가 세트에서 확인할 가설이다.
8. **의상 길이는 생성 결과를 직접 확인해야 한다.** 온실 첫 시안이 의도한 것보다 짧은 치마로 나와 보류하고, 무릎 아래 길이를 명시한 재생성 결과를 채택했다.

## 계속 적용할 생성 루프

1. 이 문서의 탐구 지도에서 덜 다룬 축을 고른다.
2. 한 묶음에 여러 장을 만들 때 공통으로 유지할 외형과 각 이미지마다 바꿀 변수를 구분한다. 행동·복장·표정·화풍 중 최소 한 가지는 이미지별로 분명히 다르게 설계한다.
3. 사용자 참조 이미지의 사용 범위를 확인한다. 상황 설명 전용 또는 재사용 금지라고 했으면 이미지를 도구 입력으로 넘기지 않고, 허용된 일반적인 장면 아이디어만 텍스트로 사용한다.
4. 각 생성 결과를 에셋에 저장하거나 채택하지 않은 이유를 기록한다. 각 결과의 실제 입력 프롬프트, 경로, 도구 정보와 날짜를 남긴다.
5. **관찰**(이미지에서 실제 보이는 것)과 **해석/가설**(왜 그렇게 되었는지)을 분리해 기록한다.
6. 반복해 유용했던 지침은 공통 프롬프트나 캐릭터 바이블에 반영한다. 한 번 나온 결과는 정식 설정으로 승격하지 않는다.
7. 탐구 지도와 다음 실험 후보를 갱신해 다음 작업자에게 넘긴다.

## 새 실험 기록 형식

```markdown
### 실험 이름 — YYYY-MM-DD
- 질문:
- 고정한 외형 단서:
- 바꾼 변수: 화풍 / 구도 / 포즈 / 표정 / 복장 / 상황
- 생성 결과와 에셋 경로:
- 관찰: 결과에 실제로 나타난 점
- 해석 또는 가설: (가설이면 그렇게 표시)
- 다음 실험: 이번 결과를 확인하거나 반박할 방법
```

## 다음 탐구 후보

- 같은 전신 포즈를 3가지 화풍으로 각각 만들어 정체성 유지와 분위기를 비교한다.
- 같은 일상 장면에서 전신 원경·중경·얼굴 표정 시트를 비교한다.
- 단색 배경과 자연 배경을 각각 사용해 날개와 머리 실루엣의 가독성을 본다.
- 계절에 따라 의상을 바꾸되 별 핀·청록 리본·흰 날개 중 무엇이 인식에 가장 크게 기여하는지 살핀다.
- 비슷한 미소라도 눈매·입 모양·고개 기울기를 달리해 표정 범위를 확장한다.
- 한 장면을 전신 원경과 인물 중심 중경으로 각각 구성해 행동과 배경 정보의 균형을 비교한다.
