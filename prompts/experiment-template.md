# 이미지 생성 실험 템플릿

새 묶음을 설계할 때 복사해 사용한다. 각 결과가 비교 가능한 질문을 갖게 하되, 모든 프롬프트를 같은 구도와 그림체로 제한하지 않는다.

배경과 컷아웃 사용 여부도 실험 변수에 포함한다. 투명 PNG를 목표로 하면 프롬프트뿐 아니라 최종 파일의 알파 채널도 확인한다.

## 묶음 계획

```text
실험 이름:
이번 질문:
공통으로 유지할 달리아 외형:
이미지에 전달할 참조 입력: 없음 / 파일과 사용 목적
첨부 이미지 사용 제한:
공통 장면 조건:
이미지별로 바꿀 변수:
예정 결과 수:
저장할 분류 폴더:
배경/알파: [배경 장면 / 투명 컷아웃]
```

## 이미지별 프롬프트

```text
DAHLIA💫 with [필요한 핵심 외형 단서].
Scene and action: [누가/어디서/무엇을 하는지]
Expression and gaze: [표정과 시선]
Pose and framing: [자세, 전신 여부, 화면 가장자리 여백, 카메라 위치]
Wardrobe: [장면에 맞는 복장]
Visual treatment: [이번 이미지에서 시험할 독립적인 화풍·선화·채색·재료감]
Light and palette: [광원과 색]
Constraints: [혼자 등장, 글자 없음, 연령에 적절한 표현 등]
```

## 결과 정리

- 각 이미지를 개별 파일로 저장한다. 생성 결과가 여러 장이면 프롬프트와 파일을 1:1로 연결한다.
- 비교 실험은 비교하고자 하는 요소 하나만 고정하거나 바꾼다. 탐색 묶음은 장면·복장·화풍을 폭넓게 바꿔도 된다.
- 채택/보류와 관계없이 다음에 유용한 결과는 주제별 생성 기록에 남긴다.
- 결과를 본 뒤 관찰과 가설을 나눠 [`docs/visual-study.md`](../docs/visual-study.md)를 갱신한다.
